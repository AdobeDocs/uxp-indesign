# EPSImportPreference
EPS import preferences.

## Instance
> *Read Only* 
> 
> Boolean **isValid** 
>
> Returns true if the object specifier resolves to valid objects.
<HorizontalLine />
> *Read Only* 
> 
> Application **parent** 
>
> The parent of the EPSImportPreference (a Application).
<HorizontalLine />
> *Read Only* 
> 
> Events **events** 
>
> A collection of events.
<HorizontalLine />
> *Read Only* 
> 
> EventListeners **eventListeners** 
>
> A collection of event listeners.
<HorizontalLine />
> Boolean **opiComments** 
>
> If true, reads OPI image links in the imported EPS file. If false, preserves the OPI links but does not read them.
<HorizontalLine />
> Boolean **epsFrames** 
>
> If true, applies clipping paths stored in the EPS file.
<HorizontalLine />
> CreateProxy **epsProxy** 
>
> Indicates when to create preview images.
<HorizontalLine />
> Object **properties** 
>
> A property that allows setting of several properties at the same time.
